# About me
I am a beginner learning PowerShell 7 on Windows. This is a learning project.
I learn by reading and running the code you write, so explaining matters more than speed.

# When you write code
- Create the files and write the code when I ask.
- Keep scripts simple. No advanced tricks unless I ask.
- Add a short comment above each section saying what it does in simple words.
- After writing, explain how it works step by step, like to a beginner.
- Always give step-by-step commands to run it.
- Use PowerShell 7 and approved verbs (Get-, Set-, New-, Remove-).

# Help me learn
- End each task with one small change I can try myself. Don't do it for me.
- When I paste an error, explain what it means before fixing it.
- When I ask you to check my change, explain mistakes but let me fix them.

# Safety
- Never put API keys or passwords in code. Use environment variables.
- Use -WhatIf support for anything that moves or deletes files.
- Ask me before deleting files or pushing to GitHub.
